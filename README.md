# Astoria Hub

Astoria Hub is an all-in-one productivity dashboard for managing the everyday essentials from one place: tasks, schedule, budget, meals, wellness habits, and notes.

## Features

- Priority task planner with add, complete, delete, and search interactions.
- Daily schedule cards for appointments and routines.
- Budget snapshot with income and expense tracking examples.
- Meal plan, habit tracking, and quick notes sections.
- Responsive, polished UI built with dependency-free HTML, CSS, and JavaScript.

## Getting started

```bash
npm run start
```

## Production build

```bash
npm run build
```
